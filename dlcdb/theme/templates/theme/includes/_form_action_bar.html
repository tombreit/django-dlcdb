Params: cancel_url href for the Cancel link (usually ``index_url``). submit_label (optional) submit button text; defaults to "Save changes". save_as_new_url (optional) add URL of the same model, like the admin's "Save as new". Set it only when the user may add. The button re-posts this form there via ``formaction``; the add view then creates a fresh object from the posted fields, or re-renders its add form with the validation errors (e.g. a unique field that must change). With two save buttons, Cancel moves to the right edge so it is not read as a third save variant. {% endcomment %}
