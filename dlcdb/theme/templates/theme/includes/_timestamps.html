{% comment %} Both audit timestamps of a row in a single table cell: when it was last modified (the primary value, which is what this column has always shown) and when it was added (secondary, muted). A row nobody has edited yet would print the same value twice — auto_now_add and auto_now both stamp on insert — so it collapses to the "added" line alone, which then renders as the cell's only, unmuted value. See AuditBaseModel.is_unmodified.
