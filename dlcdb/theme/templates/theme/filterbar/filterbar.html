{% load i18n %} {% comment %} Reusable search/filter/sort bar. Include with: {% include "theme/filterbar/filterbar.html" with bar=filterbar %} where ``filterbar`` is built in the view via dlcdb.theme.filterbar.build_filterbar(). The bar submits plain GET to the current path; HTMX swaps ``bar.target``. Active filter chips are rendered separately inside the swapped fragment via theme/filterbar/chips.html (so they refresh with every response while the bar itself keeps focus state). One rail: the search field and one joined button group (filters, "More filters", sort), both small and in the form-control tone (``filterbar-btn``). Bootstrap does the joining: each filter is a nested ``btn-group`` holding its dropdown, as documented for button groups with dropdowns. Every button says ``btn-sm`` itself: ``btn-group-sm`` sizes only direct children, not the buttons of nested groups. On viewports below md the filter/sort dropdowns fold into an offcanvas panel behind a "Filters (n)" button; search stays visible. {% endcomment %}
