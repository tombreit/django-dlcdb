Caller passes: label - visible link label asc - OrderingFilter param value for ascending (e.g. "device") desc - param value for descending (e.g. "-device") hide_idle_caret - optional; drop the "sortable" marker while this control is not the active sort. Set it where several links share one header and a row of faint arrows would just be noise.
